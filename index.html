開始學習

01 / 什麼是類別與物件？

先認識物件導向程式設計（OOP）最重要的三個觀念。

01

類別 Class

類別就像「設計圖」，定義物件有哪些資料與功能。例如：學生類別。

02

物件 Object

物件是根據類別建立的實際個體。同一個類別可以建立多個學生物件。

03

屬性與方法

屬性保存資料（例如姓名）；方法是物件可以執行的功能（例如自我介紹）。

02 / 第一個 Python 類別

以下程式建立 Student 類別，並產生一位學生物件。

student.py
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"大家好，我是{self.name}，今年{self.age}歲。")

student1 = Student("小明", 20)
student1.introduce()

執行結果

大家好，我是小明，今年20歲。
重點整理： __init__ 是建立物件時執行的初始化方法；self 代表目前的物件；student1 是 Student 類別建立出來的物件。

03 / 一個類別，多個物件

每個物件可以有自己的屬性值，互不影響。

multiple_students.py
student1 = Student("小明", 20)
student2 = Student("小美", 19)

student1.introduce()
student2.introduce()
大家好，我是小明，今年20歲。
大家好，我是小美，今年19歲。

這就是類別的好處：可以重複使用相同的設計，建立不同資料的物件。
