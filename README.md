# Python 類別與物件互動學習網頁

使用 HTML、CSS、JavaScript 製作的繁體中文 Python OOP 教學網站，包含類別、物件、屬性、方法、`__init__`、`self` 教學與三題互動測驗。

## 本機開啟
直接用瀏覽器開啟 `index.html` 即可。

## 上傳 GitHub
1. 在 GitHub 建立新的公開 Repository。
2. 點選 Add file → Upload files，上傳 `index.html` 和 `README.md`。
3. 點選 Commit changes。

## 部署 Netlify
1. 登入 https://app.netlify.com/ 。
2. 選擇 Add new project → Import an existing project。
3. 連接 GitHub 並選擇剛建立的 Repository。
4. 此網站不需 Build command；Publish directory 設為 `.`（專案根目錄）。
5. 點選 Deploy，等待取得網站網址。

也可以使用 Netlify 的手動部署，將包含 `index.html` 的資料夾拖曳上傳。
